##  Repository Structure

The repository is organized progressively to build a strong foundation in C++ before diving into core OOP paradigms:

| S.No. | Topic / Module | Description |
| :---: | :--- | :--- |
| **1** | **Basic Data Types** | Programs exploring fundamental types (`int`, `float`, `char`, `double`), type casting, and basic I/O operations. |
| **2** | **If-Else** | Decision-making constructs, nested conditions, and logical operator implementations. |
| **3** | **Loop and Array** | Iteration techniques (`for`, `while`, `do-while`), 1D/2D arrays, and memory traversal. |
| **4** | **Functions** | Modular programming, function overloading, pass by value vs. pass by reference, and recursion. |
| **5** | **Class and Object** | Introduction to user-defined data types, encapsulation, and member accessibility (`public`, `private`, `protected`). |
| **6** | **Constructor and Destructor** | Object lifecycle management, default/parameterized constructors, copy constructors, and clean-up using destructors. |
| **7** | **Static Member** | Shared class-level variables and functions that persist across all instances of a class. |
| **8** | **Inline and Friend Function** | Performance optimization via inline functions and controlled access to private data using friend functions. |

---

## Key Concepts 

* **Procedural to Object-Oriented Shift:** Transitioning from traditional control flows (loops and conditions) to designing autonomous, encapsulated classes and objects.
* **Memory & Lifecycle Management:** Understanding how objects are instantiated, how constructors initialize states, and how destructors prevent resource leaks.
* **Access Control & Encapsulation:** Leveraging friend functions and static members to manage data security and state sharing efficiently.
